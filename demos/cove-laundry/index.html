    How the real app works

    Built for a working accommodation operator. This page recreates it in the browser with a fictional hotel.

    • One codebase, two apps. React Native and Expo Router build the staff Android app and the guest web app from the same screens.
    • Rules in the database. Supabase enforces one open basket per room, five per room a day, fifty per property a day, and valid room numbers only.
    • Push when it's ready. An edge function sends a web push through Firebase as soon as staff mark a basket complete.
    • Works with no signal. Staff can log and finish a basket fully offline; it uploads by itself once the phone reconnects.
    • A dashboard for managers. Orders per day, turnaround, status mix, staff output and busiest rooms.
