HOW TO ADD YOUR APP SCREENSHOTS
================================

You don't need to edit any HTML. Save each screenshot with the exact
file name below and it replaces the dashed placeholder automatically.
Any file you haven't added yet keeps showing its placeholder.

Phone screenshots (Cove Laundry) look best as tall PNGs straight off the
phone (e.g. 1080 x 2280). Simple Stock screenshots come from the
desktop (Electron) app window and are shown at their real size, so
take them at full size rather than cropping them small. The portrait photo can be any 4:5 JPG.

images/simple-stock/   (landscape screenshots, any width; they're shown uncropped)
  hero-desktop.png                  Home screen; also used as the home page cover
  hero-stocktake.png                Stock take
  hero-bookin.png                   Book in: pick the supplier
  feature-bookin.png                Book in linked to an order
  feature-bookout.png               Workers list / booking out to a worker
  feature-costing.png               Supplier costing comparison
  feature-overview.png              Stock Overview on the home screen
  feature-requests.png              Stock requests list or detail

images/cove-laundry/   (screenshot the live demo in demos/cove-laundry)
  cover-1.png                       Home page featured row: guest view
  cover-2.png                       Home page featured row: staff view
  hero-1.png                        Guest: New Order (photo + items)
  hero-2.png                        Guest: My Orders with status
  hero-3.png                        Staff: Queue
  hero-4.png                        Staff: basket detail with stages
  feature-items.png                 Item checklist being ticked off
  feature-limits.png                Order limit message
  feature-offline.png               Basket logged with no signal
  feature-dashboard.png             Manager dashboard (landscape, 16:9)

  Tip: in Chrome press F12, then Ctrl + Shift + M, pick a phone size,
  and use the "Capture screenshot" command (Ctrl + Shift + P) to get
  clean phone-sized shots of just the app screen.

The Last Conjuration page uses the cover, screenshots and gameplay
video from your itch.io page directly, so there's nothing to add for it.

before you publish a screenshot.
